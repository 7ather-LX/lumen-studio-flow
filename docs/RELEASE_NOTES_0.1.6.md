## 新增

### 参考图 img2img

创作页新增「参考图（可选）」：

- 拖入或选择一张本地图片
- 用参考强度控制保留程度
- 参考图只在本机处理，不上传

推荐：

| 目标 | denoise |
| --- | --- |
| 借光影/质感，角色要变 | 0.60–0.68 |
| 借构图 + 质感 | 0.45–0.55 |
| 轻微调色 | 0.30–0.40 |

## 实测对比

结论：

- 参考图对 2.5D 皮肤、光影、湿润感提升明显
- 但会带进原图构图、发色和配件
- 0.62 这个强度能把棕发参考图拉成白毛柴郡，同时保留质感
- 角色完全一致仍然需要角色 LoRA 或角色参考适配器
