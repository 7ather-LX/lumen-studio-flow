# 参考图 img2img 对比

测试目标：

```text
2.5D 泳装柴郡，池边夜景
```

三组：

1. 之前：床上女仆柴郡，512×512，20 步
2. 纯提示词：泳池女仆柴郡，512×768，20 步
3. 参考图：用户提供的 2.5D 图例，img2img，denoise 0.62

![对比](cheshire-reference-compare.png)

## 观察

### 旧版：床上女仆

- 角色识别基本正确
- 2.5D 质感一般
- 皮肤高光、布料和环境光比较平
- 512 方图，构图空间小

### 新版：纯提示词

- 白毛、蓝眼、女仆装，角色更接近柴郡
- 池边夜景、黑丝、水面反光都出来了
- 2.5D 质感比旧版好
- 但皮肤和光线的层次仍然偏“模型默认输出”

### 新版 + 参考图

- 皮肤高光、湿润感、环境反射明显更强
- 池边、夜景灯光、球体、水面反射更接近参考图
- 2.5D 厚涂质感最接近用户给的图例
- 但参考图的构图和配件（墨镜、蓝花）会被带进来
- 角色身份需要靠更明确的角色 tag 和高 denoise 才能拉回来

## 结论

参考图对 **质感** 的提升非常明显，但会同时带来：

- 原图构图
- 原图配件
- 原图发色/服装倾向

所以参考图强度要按目标选择：

| 目标 | 推荐 denoise |
| --- | --- |
| 只借光影/质感，角色要变 | 0.60–0.68 |
| 借构图 + 质感 | 0.45–0.55 |
| 只轻微调色/质感 | 0.30–0.40 |

这次为了把棕发参考图改成白毛柴郡，用了 **0.62**，效果比较平衡。

## 代价

- 参考图是本地输入，不上传
- 参考图版权由使用者负责
- 0.62 会改变原图细节，不是“只学画风”
- 真正的风格参考应该用 IP-Adapter/LLLite，而不是 img2img
