GUIDE

Lumen Studio Flow

第一次用建议先看图文教程：从装好到调好每一个参数，全部配套实拍示例图。

1. 安装与启动

  1. 安装包默认创建桌面快捷方式，安装目录可以自己选择，建议放在 F 盘。
  2. 首次启动后在“设置”里确认 ComfyUI 目录、Python 路径和 F 盘输出目录。
  3. 本地模型放在：models/diffusion_models、models/text_encoders、models/vae、models/loras。
  4. 点左下角“启动本地引擎”，等到 ComfyUI 在线再生成。

2. 性能档

自动识别会读取可用显存；低于 3.5GB 自动切低显存。快速档用旧 Anima，质量档用 2.9B，低显存为 512×768、16 steps、batch 1。接入本地大模型后优先选低显存或在设置里勾选 --lowvram。

3. 图生图 / 参考

上方参考图负责构图和画风；下方角色参考负责锁角色。建议重绘幅度 40%–55%，角色引导 5–8。想让参考图画风直接进入结果时，把风格 LoRA 强度调到 0；需要某个画风时再单独提高。

“以当前图重绘”会继承 prompt、negative 和 seed；“借鉴这张”会切换为角色参考。参考图加载后画幅自动跟随，点画幅按钮可以覆盖。

4. 训练素材

在“训练素材”里拖入图片，选择常见类型或输入自定义类型。自定义类型只能用小写字母、数字、下划线或连字符；显示名称、触发词和说明会写入 training/labels.json，后续训练脚本可读取这个词汇定义。

5. 作品管理

“作品”页支持勾选、全选、收藏和批量再加工。批量再加工会把第一张选中作品载入创作页，再改参数重新生成；收藏保存在本机 localStorage。

6. API 与本地生成

本地生成没有次数限制。只有把引擎切到外部 API 时才会使用外部额度；外部额度不会锁住本地 ComfyUI。API 地址、模型和 Key 在设置里填写。

7. 关闭与显存

关闭软件时会结束由软件启动的 ComfyUI 进程树，释放显存和内存；外部启动的 ComfyUI 不会被误杀。若显存仍未释放，可在任务管理器确认 python.exe 是否退出。

8. 参数说明（重要）

重绘幅度（denoise）：决定「保留多少参考图」。30% 只补细节；45% 换材质和光影、构图基本不变；70% 换角色但保动作；85–90% 才是换角色 + 换质感的正区间。低于 0.8 会残留参考图的发色与五官特征，2.5D 厚涂换角色请用 0.88。

风格 LoRA 强度：0 表示不额外加载画风 LoRA，完全靠提示词和参考图；0.4–0.6 会明显带偏向；1.0 是满强度。2.5D 厚涂本身不需要 LoRA，保持 0–0.3 更干净。

步数：每张图采样多少步。20 步够快、32 步细节更稳；低于 16 步容易糊。CFG：提示词服从度。3.5 更柔和、4.5 更贴提示词、6 以上容易过饱和和崩结构。

种子（seed）：同 seed + 同参数 = 同构图，便于比较。想复现某张就填回那张的 seed；每次换 seed 才能得到新构图。

出图档位：一次设好「重绘幅度 + 风格强度」的组合，省得手动试。选完仍可手动微调。

构图档位：按你要的构图直接设好画幅和推荐重绘幅度。实测结论——特写用 3:4 + 88%，半身用 2:3 + 82%，全身/全景用 16:9 + 75%。全景千万不要用 0.85 以上：提示词会压过参考图，人物缩小、跑色，甚至把整张图重画成特写。另外提示词里的构图词（close-up / cowboy shot / full body）必须和你要的构图一致，否则再低的 denoise 也留不住构图。

9. 常见问题

找不到 ComfyUI：目录要选到包含 ComfyUI 和 python_embeded 的那一层。

角色不像：换复杂度更高的官方/立绘参考，角色引导提高到 6–8，并检查 negative 是否包含 hat / sunglasses / 错误发色。

黑帽/墨镜：在 negative 加 hat, cap, beret, top hat, sunglasses, goggles，默认三张里筛一张。

床上蓝发污染：不要用蓝发床图做构图参考，改用黑发床图。
